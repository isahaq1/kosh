# @kosh/reporting

Pivot engine (GROUPING SETS / ROLLUP / CUBE), comparisons, scheduled reports, PDF designer, Excel export (RFC 0005)

Part of [Kosh](https://github.com/isahaq1/kosh), a modern ERP framework on TypeScript, PostgreSQL and the
[Shutro](https://github.com/isahaq1/shutro) ORM.

```sh
pnpm add @kosh/reporting
```

Documentation: [docs/reporting.md](https://github.com/isahaq1/kosh/blob/main/docs/reporting.md) · design: [RFCs](https://github.com/isahaq1/kosh/tree/main/docs/rfcs)

Node.js 24 or later; ESM only.
