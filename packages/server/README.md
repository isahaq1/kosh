# @kosh/server

Fastify app, module loader, REST/OpenAPI generator, auth, Shutro environment per request (RFC 0002)

Part of [Kosh](https://github.com/isahaq1/kosh), a modern ERP framework on TypeScript, PostgreSQL and the
[Shutro](https://github.com/isahaq1/shutro) ORM.

```sh
pnpm add @kosh/server
```

Documentation: [docs/server.md](https://github.com/isahaq1/kosh/blob/main/docs/server.md) · design: [RFCs](https://github.com/isahaq1/kosh/tree/main/docs/rfcs)

Node.js 24 or later; ESM only.
