# @kosh/modules-sdk

defineModule, defineView, defineMenu, defineAction, defineReport, defineNotification (RFC 0001)

Part of [Kosh](https://github.com/isahaq1/kosh), a modern ERP framework on TypeScript, PostgreSQL and the
[Shutro](https://github.com/isahaq1/shutro) ORM.

```sh
pnpm add @kosh/modules-sdk
```

Documentation: [docs/modules.md](https://github.com/isahaq1/kosh/blob/main/docs/modules.md) · design: [RFCs](https://github.com/isahaq1/kosh/tree/main/docs/rfcs)

Node.js 24 or later; ESM only.
