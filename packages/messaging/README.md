# @isahaq/kosh-messaging

Chatter, followers, activities, internal chat and channels (RFC 0006)

Part of [Kosh](https://github.com/isahaq1/kosh), a modern ERP framework on TypeScript, PostgreSQL and the
[Shutro](https://github.com/isahaq1/shutro) ORM.

```sh
pnpm add @isahaq/kosh-messaging
```

Documentation: [docs/messaging.md](https://github.com/isahaq1/kosh/blob/main/docs/messaging.md) · design: [RFCs](https://github.com/isahaq1/kosh/tree/main/docs/rfcs)

Node.js 24 or later; ESM only.
