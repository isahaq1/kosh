# Bangla glossary for Shutro ERP labels

The terms every module's `src/i18n/bn.ts` uses, so the same English word reads the same in every app. Standard
Bangladeshi business Bangla (as in Bangladesh Bank, NBR and corporate usage); widely used English loanwords are kept
where Bangla offices use them (VAT, PDF, email, SKU). Keep `{{placeholders}}` exactly; keep numbers and codes.
